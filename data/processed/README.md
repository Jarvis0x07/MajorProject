# Processed data and model outputs

Everything here is generated from the source export `data/raw/clinical.project-tcga-ov.2026-10-09.json`. Each folder below names the command that regenerates it.

## Current system: `digital_twin_rl/`

Generated by `python -m digital_twin_rl all`, or by the individual steps named in brackets.

| Path | Contents |
|---|---|
| `patient_histories.jsonl`, `treatment_lines.csv`, `cohort_summary.json`, `regimens.json` | Treatment-line histories and the 14-regimen action space (`data`) |
| `outcome_ensemble.pt`, `outcome_model_report.json` | The 10-network outcome model and its held-out accuracy (`train-twin`) |
| `twins/patient_twins.jsonl` | One twin card per patient: starting state, history, prediction for every regimen (`twins`) |
| `twins/twin_database.json`, `twins/neighbor_twin_report.json` | Stored-twin database for on-the-spot twins, and the 5-nearest-twin evaluation (`twin-db`) |
| `agents/` | Trained DQN and DQN+BCQ agents with their learning curves (`train-agent`) |
| `evaluation/` | Simulation fidelity, policy comparison, per-patient recommendations, figures (`evaluate`) |
